## Image and licence limits

Seven direct reference-photo URLs were retrieved: GUBI lifestyle, Muuto Connect Soft, Muuto Outline, West Elm Ida, and three Bosch shots. Two Muuto dimension drawings are also recorded. Null image fields mean the source gallery did not expose a direct usable URL; no URLs were invented.

The Connect Soft photo shows **Configuration 2 / Ecriture 910**, while its verified dimensions belong to the default **Configuration 1 / Clay 12**. The Outline packshot shows **cognac leather / aluminium**, while default page data describes **Clay 12 / black**. The oven shot is the manufacturer’s shared file labelled HBA7741B1, linked from HBG7741B1B. Keep these variant differences visible in any reference treatment.

GUBI and West Elm pages state all rights reserved, and Muuto has a copyright notice. Public image availability is not an open asset licence. [Bosch UK’s terms](https://www.bosch-home.co.uk/products/terms-of-website-use) permit personal-reference extracts, require attribution, restrict modification and separate photo use, and require a licence for commercial reuse. Singapore Bosch terms were not inspected. Link to original product pages; the images are reference material, not licensed 3D models.

## Verification gaps

Publication dates are unknown unless an explicit brand/Pinterest announcement date is recorded. Current GUBI dimensions were not exposed; an older page now returns 404, so its old dimensions were excluded. Article’s official index confirms Nera’s product identity, Queen size and Oak finish, but its full page could not be parsed. West Elm’s multiple size data could not be confidently matched to one selected Ida variant, so dimensions are null. No reseller dimensions were accepted.

Muuto’s Connect Soft metric dimensions are clearly displayed, but the page’s height-in-inches value is inconsistent; the catalog retains centimetres only. Bosch oven/fridge dimensions are saved in their displayed order because axis labels are absent in the parsed technical overview. Dishwasher packed dimensions were excluded. Dimensions are not installation or fit checks.

Only Behr’s **Hidden Gem #596D69 / RGB 89,109,105** had directly retrieved official digital colour values. No guessed or third-party hex values were supplied for Silhouette or Universal Khaki. Benjamin Moore cautions that screen/print colours may differ from actual paint.
