# K4 Kitchen Storage Audit

Status: **COMPARATIVE DESIGN AUDIT — NOT NET MANUFACTURER LITRES**

Purpose: answer the original concern that opening the kitchen might remove too much storage.

This uses simplified cabinet-envelope assumptions consistently across the baseline and K4. It is useful for comparison, not for claiming exact usable litres after carcass thickness, hinges, plumbing, shelves and drawer hardware.

## Assumptions

- Base-cabinet storage height reference: ~740 mm.
- Upper cabinet: 700 mm high × 330 mm deep.
- Pantry / oven column: 2200 mm tall × 600 mm deep.
- Baseline west run assumes roughly one 600 mm under-counter oven position, leaving ~900 mm of the 1500 mm run as ordinary base storage.
- Sink cabinets receive a conservative reduction for bowl/trap/services.
- K4 oven column subtracts an approximate 600 × 550 × 595 mm oven envelope.
- K4 island reception side is modeled around 280 mm useful shallow depth and discounted for service interference.
- Dishwasher, fridge and washer volumes are not counted as storage.

## Baseline closed kitchen — rough comparative envelope

| Element | Approx. storage envelope |
|---|---:|
| West-run storage after oven allowance | ~0.400 m³ |
| 600 corner base | ~0.271 m³ |
| Sink base after service allowance | ~0.149 m³ |
| 600 × 410 shallow landing | ~0.182 m³ |
| Upper cabinets: 1800 + 300 + 450 mm | ~0.589 m³ |
| **Total comparison envelope** | **~1.59 m³** |

This is already generous to the corner cabinet because real corner access is usually less efficient than its gross box volume.

## K4 open kitchen — rough comparative envelope

| Element | Approx. storage envelope |
|---|---:|
| 1800 cooking bases, discounted for hob/services | ~0.719 m³ |
| 600 full-height pantry | ~0.713 m³ |
| Oven-column residual storage after oven envelope | ~0.596 m³ |
| 550 sink module after service allowance | ~0.134 m³ |
| 550 island drawer/bin module | ~0.244 m³ |
| 1700 mm reception-side shallow island storage | ~0.299 m³ |
| Two 600 mm uppers | ~0.277 m³ |
| **Total comparison envelope** | **~2.98 m³** |

## Conclusion

Under the same simplified comparison method, K4 is approximately:

**2.98 / 1.59 ≈ 1.87× the baseline storage envelope**

So the full-open kitchen is **storage-positive**, not storage-negative, despite losing the long north-wall upper run.

The gain comes mainly from:
- full-height 600 mm pantry,
- moving the oven into a tall column and using the rest of the column,
- three useful 600 mm cooking-base modules,
- double-sided 1700 × 900 island,
- eliminating the indoor washer from the main kitchen cabinet run.

## Storage-quality advantage

K4 also improves the *type* of storage:
- pantry shelves for food / bulk items,
- wide drawers near hob for pots and utensils,
- waste sorting beside sink,
- dishwasher beside sink,
- shallow reception-facing island storage for serving pieces / less-used items,
- tall appliance storage around oven.

This is generally more accessible than relying heavily on corner cabinets and upper cabinets.
