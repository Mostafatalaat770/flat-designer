## What is not yet quantified

Do not order based on this file for:
- bathroom wall tiles
- kitchen backsplash slab/tile
- skirting
- paint
- gypsum
- waterproofing
- worktop
- joinery sheets/boards
- curtain fabric
- thresholds/transitions

Those need elevations / perimeter deductions and final material formats.

## Procurement rule

Before final floor order:
1. confirm actual site dimensions
2. freeze tile/plank dimensions
3. draw setting-out / plank direction
4. decide threshold details
5. confirm batch/calibre/shade availability
6. obtain installer waste recommendation
7. buy one production batch where shade consistency matters
