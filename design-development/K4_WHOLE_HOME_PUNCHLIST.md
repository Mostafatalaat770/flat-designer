# K4 Whole-Apartment Design Punch List

Use this as the gate between **layout design** and **construction / procurement package**.

## Public zone

### Entry
- [ ] Final shoe-storage elevation and internal capacity.
- [ ] Key/charging/drop zone.
- [ ] Mirror final size/height.
- [ ] Verify open main door + dining chair clearance on site.
- [ ] Door stop / handle protection.

### Living
- [ ] Final sofa/chair products and upholstery samples.
- [ ] TV size, centre height, viewing distance and concealed cable route.
- [ ] Side tables and convenient outlets.
- [ ] Final rug size after actual sofa/chair purchase.
- [ ] Full-height curtain track / sheer / drapery build-up.
- [ ] Acoustic softness: rug, curtains, upholstery; avoid excessive hard-surface echo.
- [ ] Final art scale and fixing locations.
- [ ] Floor lamp / table lamp product choices.

### Dining
- [ ] Confirm 2000 × 950 table remains right after final chair products.
- [ ] Sideboard elevation, depth, internal storage and lamp outlet.
- [ ] Keep the H2 150 mm north shift unless site dimension disproves it.
- [ ] Confirm no chandelier is required; retain optional future ceiling point only if useful.

### Kitchen
- [ ] Structural/developer sign-off for full opening.
- [ ] K3/K4 indoor laundry strategy confirmed.
- [ ] Exact fridge / washer / DW / oven / gas hob / hood SKUs.
- [ ] Gas + exhaust + make-up-air coordination.
- [ ] Island plumbing + power route.
- [ ] 1700 × 900 island shop drawing with 400 storage + 600 DW + 600 sink + 100 end allowance concept.
- [ ] Reception-side shallow island storage details.
- [ ] Worktop slab/joint/edge/sink cut-out.
- [ ] Pantry internals + microwave/coffee appliance garage.
- [ ] Under-cabinet LED and driver access.
- [ ] Tall-wall fillers / ventilation / service access after site measure.
