## What a site return should contain

- Numbered dimensioned, dated photos, with drawing origin and actual as-built room measurements, current kitchen door and both wall faces.

- Proposed solution status **PASS / REVISE / REJECT / UNRESOLVED** for each RFI and responsible person; no inferred signatures.
