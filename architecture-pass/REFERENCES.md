# Authoritative planning / engineering references

Accessed 2026-10-06. These sources support the review process; they are not a substitute for project-specific professional approval.

## Egypt — governing / primary

- Housing & Building National Research Center (HBRC), Egyptian codes and specifications:
  https://hbrc.edu.eg/ar/services/code-egypt
  The code catalog includes structural/load, reinforced-concrete, building execution, energy, accessibility and other Egyptian code families. Obtain the current applicable editions for construction review.

- HBRC historical summaries / building-work code families:
  https://www.hbrc.edu.eg/ar/egyptian-code-2
  Includes categories for load-bearing walls, non-load-bearing partitions and sanitary installations. The page warns that listed historical summaries are not necessarily current; use the active code catalog/current purchased edition for sign-off.

- Egyptian Ministry of Petroleum / Town Gas residential natural-gas safety notice:
  https://www.petroleum.gov.eg/ar-eg/media-center/news/news-pages/Pages/mop_02022022_01.aspx
  Gas equipment and fittings must not be altered by unqualified persons; approved companies and ventilation/safety requirements apply.

- EGAS HSE guidelines:
  https://www.egas.com.eg/sites/default/files/2022-07/Annex%20-5%20EGAS%20HSE%20guidelines-Updated.June_.%202022%20%281%29.pdf
  Includes in-apartment conversion/installation inspection and ventilation/flue safety checks. Selected gas-appliance installation must still follow the responsible gas company and manufacturer.

## Professional kitchen / bath planning

- NKBA Kitchen & Bath Planning Guidelines, current fifth edition:
  https://nkba.org/planning-guidelines/
- NKBA announcement describing the 2026 fifth edition and its 2024 IRC / CSA B652 basis:
  https://nkba.org/news/member-industry-news/newly-updated-kitchen-bath-planning-guidelines/
- Public legacy NKBA numerical planning reference used only where the fifth-edition exact number is not publicly accessible:
  https://media.nkba.org/uploads/2022/05/Kitchen-Planning-Guidelines.pdf
  Public 4th-edition guidance includes 1067 mm one-cook / 1219 mm multi-cook work aisles. Treat this as professional planning guidance, not Egyptian law.

## Appliance rule

For every selected appliance, use the exact current manufacturer installation manual for cutout, ventilation, heat separation, door/drawer sweep, water/drain/gas/electrical connection, service access and anchoring. Generic envelope dimensions are only design reserves.

## Precedence

When sources conflict:
1. Egyptian law / authority / developer requirements.
2. Structural / MEP engineer requirements and responsible utility/gas company.
3. Exact product manufacturer instructions.
4. Professional planning standards such as NKBA.
5. Project comfort targets and aesthetic preferences.
